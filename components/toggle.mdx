The Toggle component is a two-state button that switches between "on" and "off" — ideal for toolbar formatting controls like Bold, Italic, or Underline, or for any feature that can be enabled and disabled. It is built directly on the native `<button>` element with `aria-pressed` to communicate state to assistive technology. The browser provides click and keyboard (Enter/Space) handling automatically. A small JavaScript module wires up `aria-pressed` toggling; the visual states are driven entirely by CSS reacting to `aria-pressed="true"`.

## CDN Import

```html
<!-- CSS -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/codylindley/shadcn-html@latest/dist/components/toggle/toggle.css">
<!-- JS (required for aria-pressed toggling) -->
<script type="module" src="https://cdn.jsdelivr.net/gh/codylindley/shadcn-html@latest/dist/components/toggle/toggle.js"></script>
```

## Basic Usage

Add the `.toggle` class to a `<button>` and set the initial `aria-pressed` state. The JS module handles toggling `aria-pressed` on click.

```html
<button class="toggle" aria-pressed="false" aria-label="Toggle bold">
  <svg aria-hidden="true" width="16" height="16" viewBox="0 0 24 24"
       fill="none" stroke="currentColor" stroke-width="2"
       stroke-linecap="round" stroke-linejoin="round">
    <path d="M6 12h9a4 4 0 0 1 0 8H7a1 1 0 0 1-1-1V5a1 1 0 0 1 1-1h7a4 4 0 0 1 0 8"/>
  </svg>
</button>
```

## With Text

Include both an icon and a visible text label.

```html
<button class="toggle" aria-pressed="false">
  <svg aria-hidden="true" width="16" height="16" viewBox="0 0 24 24"
       fill="none" stroke="currentColor" stroke-width="2"
       stroke-linecap="round" stroke-linejoin="round">
    <path d="M19 4H9.5a4.5 4.5 0 0 0 0 9H13"/>
    <path d="M5 20h13.5a4.5 4.5 0 0 0 0-9H9"/>
  </svg>
  Italic
</button>
```

## Variants

| `data-variant` | Visual |
|---|---|
| *(default)* | Transparent background with subtle hover |
| `outline` | 1px border with transparent background |

```html
<button class="toggle" aria-pressed="false">Default</button>
<button class="toggle" data-variant="outline" aria-pressed="false">Outline</button>
```

## Sizes

| `data-size` | Height | Padding | Min-Width |
|---|---|---|---|
| `sm` | 2rem | 0 0.375rem | 2rem |
| *(default)* | 2.25rem | 0 0.5rem | 2.25rem |
| `lg` | 2.5rem | 0 0.625rem | 2.5rem |

```html
<button class="toggle" data-size="lg" aria-pressed="false" aria-label="Bold (large)">
  <svg aria-hidden="true" width="18" height="18" ...>...</svg>
</button>
```

## Pressed State

The JS module toggles `aria-pressed` between `"true"` and `"false"` on each click. The CSS uses `aria-pressed="true"` as the selector for the active/pressed visual state, using `--accent` / `--accent-foreground` tokens matching shadcn conventions.

To render a toggle in its pressed state by default (e.g., bold is currently active), set `aria-pressed="true"` in the HTML:

```html
<button class="toggle" aria-pressed="true" aria-label="Bold — currently active">
  <svg aria-hidden="true" width="16" height="16" ...>...</svg>
</button>
```

## ARIA & Accessibility

| Attribute | Element | Value |
|---|---|---|
| `aria-pressed` | `<button>` | `"true"` when pressed, `"false"` when not |
| `aria-label` | `<button>` | **Required** for icon-only toggles without visible text |

## Wiring

The `toggle.js` module listens for `click` events on any `.toggle` button and flips `aria-pressed` between `"true"` and `"false"`. CSS then reacts to `[aria-pressed="true"]` to apply the pressed visual style. No other configuration is needed.

For programmatic control, set `aria-pressed` directly in your JavaScript:

```js
const toggle = document.querySelector('.toggle');
toggle.setAttribute('aria-pressed', 'true');  // activate
toggle.setAttribute('aria-pressed', 'false'); // deactivate
```

## Notes

<Note>
The toggle is just a `<button>` with `aria-pressed` — no custom elements, shadow DOM, or framework wrappers required.
</Note>

<Tip>
When grouping toggles for mutually exclusive options (like text alignment), wrap them in a container with `role="group"` and `aria-label`. See the [Toggle Group](/components/toggle-group) component for the complete pattern.
</Tip>

<Warning>
Icon-only toggles without `aria-label` are inaccessible to screen reader users. Always provide a descriptive label when the toggle contains only an icon.
</Warning>

- The pressed state uses `--accent` / `--accent-foreground` tokens, consistent with the shadcn design system.
- `color-mix()` is used to derive the hover color for the pressed state.
- `prefers-reduced-motion: reduce` suppresses color/background transitions.
- `prefers-contrast: more` adds visible borders.
- `forced-colors: active` maps the pressed state to the system `Highlight` color in Windows High Contrast Mode.
