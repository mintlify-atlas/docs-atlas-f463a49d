The **Alert** component displays a persistent, inline notification message directly within the page flow. Unlike a [Toast](/components/toast), an alert does not appear, animate, or dismiss automatically — it is a static element you place in your markup wherever context-specific feedback belongs, such as a form validation summary, a feature announcement, or a system status notice. It is CSS-only with no JavaScript dependency, and uses `role="alert"` (for urgent messages) or `aria-live="polite"` (for informational ones) to integrate cleanly with screen readers.

## CDN Import

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/codylindley/shadcn-html@latest/dist/components/alert/alert.css">
```

No JavaScript is needed for this component.

## Basic Usage

An alert consists of an optional icon (`.alert-icon`), a content wrapper (`.alert-content`) containing a title and description, and an optional action area (`.alert-action`).

```html
<div class="alert" role="alert">
  <svg class="alert-icon" aria-hidden="true" width="16" height="16"
       viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2">
    <circle cx="12" cy="12" r="10"/>
    <path d="M12 8v4M12 16h.01"/>
  </svg>
  <div class="alert-content">
    <h5 class="alert-title">Heads up!</h5>
    <p class="alert-description">You can add components using the CLI.</p>
  </div>
</div>
```

## Variants

Set `data-variant` on the `.alert` element to communicate intent.

| `data-variant` | Use case |
|---|---|
| *(default)* | Standard informational notice |
| `destructive` | Error, danger, or irreversible action warning |
| `warning` | Non-critical caution or advisory notice |
| `info` | Neutral informational context |
| `success` | Confirmation of a completed action |


## Alert with Action

Add an `.alert-action` container after `.alert-content` for contextual CTAs.

```html
<div class="alert" data-variant="info">
  <svg class="alert-icon" aria-hidden="true" width="16" height="16"
       viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2">
    <circle cx="12" cy="12" r="10"/>
    <path d="M12 16v-4M12 8h.01"/>
  </svg>
  <div class="alert-content">
    <h5 class="alert-title">New feature available</h5>
    <p class="alert-description">
      The redesigned dashboard is ready for you to try.
    </p>
  </div>
  <div class="alert-action">
    <button class="btn" data-variant="outline" data-size="sm">Enable</button>
  </div>
</div>
```

## ARIA & Accessibility

| Attribute | Element | Value | Purpose |
|---|---|---|---|
| `role="alert"` | `.alert` | `alert` | Triggers an assertive live region — screen readers interrupt to announce it |
| `aria-live="polite"` | `.alert` | `polite` | Announces when the element's content changes, without interrupting |
| `aria-hidden="true"` | `.alert-icon` | `true` | Marks the decorative icon as invisible to AT when a title is present |

<Warning>
  Use `role="alert"` only for genuinely urgent messages. It triggers an **assertive** announcement that interrupts whatever the screen reader is currently reading. For informational alerts, omit `role="alert"` and use `aria-live="polite"` instead.
</Warning>

## Structure Reference

| Class | Element | Purpose |
|---|---|---|
| `.alert` | `<div>` | Outer container — carries `data-variant` and `role` |
| `.alert-icon` | `<svg>` | Decorative leading icon (`aria-hidden="true"`) |
| `.alert-content` | `<div>` | Wrapper for title and description text |
| `.alert-title` | `<h5>` | Short alert headline |
| `.alert-description` | `<p>` | Supporting detail text |
| `.alert-action` | `<div>` | Optional action button area |

## Notes

- Alert is a purely CSS component — no JavaScript is needed.
- The `data-variant` attribute drives color and icon theming via design tokens from the shadcn/ui token system.
- Use an alert for persistent, in-context messages. Use a [Toast](/components/toast) for transient post-action feedback that auto-dismisses.
- Always mark icon elements with `aria-hidden="true"` when a visible `.alert-title` is present — the icon is decorative and would create redundant announcements if read aloud.
