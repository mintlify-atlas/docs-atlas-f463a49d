Shadcn HTML treats the browser as the component library. Before a single line of JavaScript is written, every feature request is first answered with a question: *can the platform do this already?* The result is a system where modal focus trapping comes from `<dialog>`, dropdown positioning comes from CSS anchor positioning, and enter animations come from `@starting-style` — not from npm packages. This native-first philosophy keeps bundle sizes near zero, keeps behavior predictable across frameworks, and ensures components degrade gracefully as the platform evolves.

## The Native-First Principle

Traditional UI libraries ship thousands of lines of JavaScript to replicate behaviors that modern browsers already provide. Shadcn HTML eliminates that overhead entirely by building directly on the platform.

## Instead Of… We Use…

| Instead of… | Shadcn HTML uses… |
|---|---|
| JS modal libraries | `<dialog>` + `showModal()` |
| JS dropdown positioning | Popover API |
| JS accordion toggle | `<details>` / `<summary>` |
| JS enter animations | `@starting-style` |
| Floating UI / Popper.js | CSS anchor positioning |
| JS class toggling for parent state | `:has()` selector |
| JS textarea auto-resize scripts | `field-sizing: content` |
| Sass / Less / PostCSS | Native CSS nesting, `@layer`, container queries |

## API Reference

Every native platform API used in shadcn HTML, what it replaces, and which components rely on it.

### HTML Elements & Attributes

| Native API | Replaces | Components |
|---|---|---|
| [`<dialog>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/dialog) | JS modal + overlay + focus trap | Dialog, Alert Dialog, Sheet, Command |
| [`<details>` / `<summary>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/details) | JS toggle + height animation | Accordion, Collapsible |
| [`<details name>` (exclusive)](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/details#name) | JS single-expand accordion logic | Accordion (single mode) |
| [`<progress>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/progress) | Custom div-based progress bars | Progress |
| [`<meter>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/meter) | Custom gauge components | Password strength, storage indicators |
| [`<output>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/output) | Manual `aria-live` regions | Slider displays, form totals, live results |
| [`inert`](https://developer.mozilla.org/en-US/docs/Web/HTML/Global_attributes/inert) | JS focus trap + `aria-hidden` toggling | Overlays, collapsed sidebars, loading states |
| [Popover API](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API) | JS show/hide, z-index management, click-outside | Popover, Dropdown, Tooltip, Toast, Combobox, Context Menu, Nav Menu |
| [`popover="hint"`](https://developer.mozilla.org/en-US/docs/Web/HTML/Global_attributes/popover) | Custom tooltip z-index management | Tooltip, descriptive hovers |
| [Invoker Commands (`commandfor` / `command`)](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/button#commandfor) | JS click handlers calling `showModal()` / `togglePopover()` | Dialog, Alert Dialog, Sheet, Popover |
