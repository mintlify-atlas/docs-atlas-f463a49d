## What is Shadcn HTML?

Shadcn HTML is a UI component library for the web platform — built without any framework, build tool, or dependency. Each component is a self-contained folder with a stylesheet, optional JavaScript, and a structured component skill file that documents its HTML structure, variants, ARIA patterns, and wiring conventions.

The design token system is fully compatible with [tweakcn.com](https://tweakcn.com) theme exports. Drop in a new `default-semantic-tokens.css` and every component rethemes at once — colors, radius, shadows, and dark mode.

## Quick Example

Load the theme tokens, icons, and one component — that's the entire setup:

```html
<!-- 1. Theme tokens (tweakcn-compatible) -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/codylindley/shadcn-html@latest/dist/theme/default-semantic-tokens.css">

<!-- 2. Lucide icons -->
<script src="https://unpkg.com/lucide@1.8.0"></script>
<script>lucide.createIcons();</script>

<!-- 3. One component -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/codylindley/shadcn-html@latest/dist/components/button/button.css">

<!-- Use it -->
<button class="btn" data-variant="default">Get Started</button>
<button class="btn" data-variant="outline">Learn More</button>
```
